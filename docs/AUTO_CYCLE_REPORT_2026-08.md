## 3. 무엇이 바뀌었나 — 5개 묶음

### (A) 구조 상환 — Phase 2 전건 완료 (08-06, 커밋 11건)
- `App.jsx`/`TimelineView.jsx` 분해: Zustand `settingsStore`/`uiStore` + 도메인 훅
  (`useTaskActions`/`useProjectSync`/`useImportExport`/`useBarDrag`/`useTimelineScale` 등).
- `src/` 를 **feature-first**(`features/{shell,table,timeline,tasks,projects,io}` + `shared/`)로 재편.
  `components/`·`hooks/` 디렉터리 소멸.
- 서버에 **Service 계층** 분리(`services/{task,data,project}Service` + `lib/httpAdapter`) —
  라우트는 HTTP 만 다룬다. 이 분리 덕분에 P3-1(SQLite 전환)의 선행 조건이 이미 충족된 상태다.
- 모달 껍데기 4벌 → 공용 `Modal` 1벌, 이모지 → Lucide 아이콘, 툴바 3그룹 재편.
- **프로젝트별 append-only 감사 로그**(`lib/eventLog.js`, `GET /api/projects/:pid/events`) — P3-2.
- TanStack Query 는 **도입하지 않기로 판단**(서버 상태 접근이 `storage.js` 한 곳에 이미 모여 있음).

### (B) 편집 경험 통합 — 인스펙터 패널 v1~v4 (08-06~08-08, 커밋 7건)
- 인스펙터 패널이 **편집 팝오버를 전부 흡수하고 폐기**했다: `TimelineBarPopover`(564줄),
  `MilestoneEditPopover`(228줄+CSS), 표의 마일스톤 관리 모달(JSX 80 + CSS 99).
  **편집 팝오버는 이제 하나도 남아 있지 않다.**
- 함께 들어온 것: 상태 기반 바 색상 + 타임라인 범례(§5.4-10), 키보드 일정 편집(↑↓·`[`·`]`),
  **명령 팔레트 Ctrl+K**(명령 검색 + 작업으로 이동).
- 설계 결정 하나: 마일스톤을 선택 단위로 **승격하지 않는다** — 선택은 작업 하나, 기간·마일스톤은
  포커스 힌트로 다룬다.

### (C) 의존성을 "그리기"에서 "판정하기"로 (08-09~08-10, 커밋 4건)
- `findDependencyIssues()` 하나로 **순환(연결 전 차단) · 일정 위반 · 끊어진 참조**를 판정.
- 같은 판정을 `server/lib/taskTree.js` 로 포팅 — **REST/MCP 쓰기도 400 으로 거부**한다.
  사후 진단은 `GET /api/projects/{pid}/dependency-issues` + MCP `check-dependencies`.
- **끊어진 참조를 생기지 않게** 바꿨다: 작업/기간/마일스톤 삭제가 자기를 가리키던
  `dependencies` 를 같은 쓰기에서 걷어낸다(화면·서버 양쪽).
- **병합 가져오기 교차 연결 제거**: 작업 id 만 재발급하고 기간·마일스톤 id 를 두던 탓에,
  같은 파일을 병합하면 **사본의 화살표가 원본에 가서 붙었다**. 세 종류 id 를 모두 재발급한다.

### (D) 조용한 소실·침묵 버그 (08-10~08-12, 커밋 7건)
공통 성격: **사용자에게는 아무 일도 없었던 것처럼 보이는데 데이터·의도는 어긋나 있던** 경로.
- **저장 실패가 `console.warn` 하나로 끝나 사용자는 저장됐다고 믿었다.** 순수 상태기계
  `syncStatus.js`(전이·백오프 2s→60s·문구) + 헤더 `SyncIndicator`(색+아이콘+텍스트, 실패 시
  즉시 재시도 버튼). 함께 닫은 소실 경로 3건: 폴링이 미저장 편집을 덮어쓰던 것,
  `beforeunload` 무경고, 프로젝트 전환 flush 실패 무통보.
- **전역 단축키에 가드가 아예 없었다**: 입력칸의 Ctrl+Z 를 앱이 가로채고, 모달 뒤에서 Ctrl+N/Z/Y
  가 발화해 보이지 않는 곳에서 트리가 바뀌었으며, `key === 'z'` 비교 탓에 Ctrl+Shift+Z 와
  CapsLock 상태의 Ctrl+Z 가 죽어 있었다. 판정을 `shared/keyboard.js` 한 곳으로 모았다.
- **검색 관련 4건**: 접힌 가지 아래 일치가 감춰지던 문제 / 검색 중 접기 토글이 죽은 버튼이던 문제
  (누른 값은 저장 데이터에만 조용히 들어갔다) / 검색 중 드래그가 화면과 다른 곳에 놓던 문제 /
  검색 중 추가한 작업이 화면에 나타나지 않던 문제.
- **역전된 기간(종료<시작)을 타이핑으로 만들 수 있었다** — 통과하면 0px 바가 되어 방금 입력한
  기간이 사라진 것처럼 보였다. `orderRangeDates()` + 관문 `patchRange` 하나로 통일.
- **연속 입력 한 번이 되돌리기 히스토리 20칸을 다 썼다**(진행률 슬라이더·색상 대화상자·키 오토리핏).
  `undoHistory.js` 의 **제스처 병합**(600ms)으로 한 칸으로 접는다.

### (E) 접히거나 걸러진 것을 침묵시키지 않기 (08-13, 08-17, 커밋 3건)
- **의존성 화살표**: 한쪽 끝이 접힌 가지·검색 밖이면 예전에는 간선을 버렸다 — "지운 것"과
  "가린 것"이 똑같아 보였다. 이제 보이는 조상 행으로 **끌어올려 그리고**, 조상도 없으면 살아남은
  끝에 **표식**을 남긴다(양쪽 다 상대 이름을 툴팁에).
- **표(TableView)에 의존성 표현 추가**: 행마다 `←n →n` + 문제 아이콘. 표만 쓰는 사용자에게는
  연결의 존재 자체가 보이지 않았다. 간선·문제는 `findDependencyIssues` 것을 그대로 쓴다.
- **접힌 가지의 일정 요약 막대**(08-17, 마지막 사이클): 접으면 자손의 기간·마일스톤은 그릴 행이
  없어지는데 가로 축은 자리를 비워 두어 *일정 없음*과 *접음*이 같아 보였다. 대표 행에 얇은 빗금
  요약 막대 + 속 빈 마름모로 끌어올린다. **겹치는 구간만 합치고 빈 사이는 비워 둔다**(1월과 12월을
